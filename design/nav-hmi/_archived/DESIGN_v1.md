# DESIGN.md — CarHi 车机导航界面（Nav-HMI）

> 面向：原型构建师（生成 HTML 静态视觉稿）
> 画布：1920 × 720 横屏（2.67:1 超宽）
> 主题：**仅深色**（车机夜间场景，安全刚需）
> 基线：Tech Utility 视觉方向（深底 + 高对比 + 大字号）+ 汽车 HMI 领域约束
> 版本：v1.0

---

## 0. 设计系统选型说明

### 关键结论：系统库中**没有专门为「车机 HMI」设计的设计系统**

71 套系统里，汽车类别下的 **Tesla / BMW / Ferrari / Lamborghini / Bugatti / Renault** 都是**品牌营销官网**的设计语言（大图、品牌色、编辑式排版），**不是车机 HMI 设计语言**。它们的深色是「展厅深色」，不是「驾驶舱深色」。

因此本项目从「**深色为主 + 高对比 + 大字号**」的维度，推荐以下最接近的系统：

| 方案 | 设计系统 | 匹配度 | 特征 | 适合原因 |
|------|---------|--------|------|---------|
| **A（推荐）** | **Tech Utility 视觉方向**（综合 Linear / Vercel / Supabase 的深色基因） | ★★★★★ | 深蓝黑底、极高对比、霓虹式强调色、数据优先 | 与车机 HMI 的「夜间可读 + 一眼扫读」需求同构；强调色克制，天然适合「只给当前动作上色」 |
| B | **Linear**（开发工具类） | ★★★★☆ | 近黑背景 #08090A、精确层级、低饱和紫蓝强调 | 层级分明、字号跨度大，最接近「仪表盘」气质；但缺少中文远距离字阶，需自行放大 |
| C | **Tesla**（汽车类） | ★★★☆☆ | 极简、纯黑底、白色大字、几乎无装饰 | 唯一「汽车血统」的最高对比方案；缺点是留白过少、组件规范稀薄，需大量补全 |

### 为什么最终选 A（Tech Utility 方向）而不是 C（Tesla）

- Tesla 官网深色是**展示型深色**（配大图和视频），缺少 HMI 需要的**组件级规范**（状态条、卡片层级、语义色）。
- Tech Utility 的优势是**信息密集 + 数据可扫读**，正好覆盖导航页的「转向指引 + 状态条」和音频页的「控制 + 进度」。
- 重要：**注意方向不要跑偏**——Tech Utility 的「等宽字体 + 霓虹绿」是开发者终端气质，本项目要**取其深色对比结构，弃其等宽字体与霓虹色**，改用中文无衬线 + 克制蓝色强调（详见第 3、7 章）。

## 1. Visual Theme（视觉主题）

**Philosophy**：驾驶者视线离开路面只有 1–2 秒，界面必须在一次扫视里被读懂——**层级靠「大小 + 亮度」拉开，不靠边框和色块**。

**Direction**：dark, calm, high-contrast, glanceable（深色、沉静、高对比、可扫读）

**Personality**：沉稳、精确、不喧哗。像夜间仪表盘——亮的地方正好是你此刻该看的地方。

**Reference**：官方百度 CarLife 的简化版 + 深色车机 HMI 惯例。

**核心原则（生成时必须遵守）**：
1. **一屏一焦点**：导航页只有「转向指引卡片」是焦点，其余元素亮度一律压低一档。
2. **亮度做层级，不做装饰**：不要用彩色边框/色块分区，用文字亮度（白 → 灰 → 暗灰）表达主次。
3. **留白即安全**：宁可少放信息，也不要把字挤到需要眯眼。
4. **零花哨动效**：静态稿不做动画；即便落地也只用 ≤150ms 的透明度过渡，禁止位移/缩放/轮播。

## 2. Color Palette（调色板 · 仅深色）

> 全部 hex 可直接落地。所有前景/背景组合均已按 WCAG AA（正文 ≥4.5:1、大字 ≥3:1）校验。
> 车机屏对比度实际观感低于手机，故**主动加严一档**：正文目标 ≥7:1。

### 2.1 背景层级（Background Layers）

| Token | HEX | 用途 |
|-------|-----|------|
| `--bg-base` | `#0A0C10` | **最底层**。整屏底色、地图区底、页签栏底。趋近纯黑但带一点冷调蓝，避免 OLED 纯黑在车内反光下显脏 |
| `--bg-surface` | `#141821` | **卡片层**。转向指引卡片、音频页曲目卡片、控制面板背景 |
| `--bg-elevated` | `#1E2430` | **浮层/交互层**。大按钮默认底、按钮组底、进度条轨道 |
| `--bg-elevated-hover` | `#28303F` | 浮层 hover/按下底（按钮 active） |
| `--bg-map` | `#0E1219` | **地图画布专用底**（比 base 略亮，让道路线框能浮起来） |

> 层级差值刻意很小（约 6–8% 亮度差）。车机夜间场景要避免「一块块亮斑」，靠**边缘对比**而非**填充对比**分层。

### 2.2 前景层级（Foreground Layers）

| Token | HEX | 用途 | 对比度(对 #0A0C10) |
|-------|-----|------|--------------------|
| `--fg-primary` | `#FFFFFF` | 最高优先级：转向距离数字、道路名、当前曲目名 | 19.6:1 ✅ |
| `--fg-secondary` | `#C3CBD9` | 次级信息：状态条文字、EAT/剩余里程、歌手名 | 11.4:1 ✅ |
| `--fg-tertiary` | `#7C879B` | 三级信息：单位后缀、标签、非激活页签 | 5.1:1 ✅（仅用于 ≥28px） |
| `--fg-disabled` | `#4A5364` | 禁用态、极次要的占位文字 | 2.4:1 ⚠️ 仅装饰，禁止承载信息 |
| `--fg-on-accent` | `#06131F` | 强调色按钮上的文字（深色字压蓝底） | — |

### 2.3 强调色（Accent · 克制使用）

只用于**当前动作 / 关键数据 / 激活态**。全屏高饱和色面积 **不超过 8%**。

| Token | HEX | 用途 |
|-------|-----|------|
| `--accent` | `#2E9BFF` | 主强调：激活页签下划线、转向箭头、播放进度已播部分、当前音量值 |
| `--accent-hover` | `#4FB0FF` | 强调元素 hover / 按下提亮 |
| `--accent-active` | `#1C7FE0` | 强调元素 active（更深，给按下反馈） |
| `--accent-dim` | `#1A3A5C` | 强调色的低亮变体：进度条剩余段、页签底、地图道路高亮底 |
| `--accent-glow` | `rgba(46,155,255,0.18)` | 强调件的柔和外发光（**仅此一处允许发光**，用于转向箭头） |

> **为什么是蓝不是绿**：绿色在车机常被视为「系统状态正常」语义色，若作主强调会与成功态冲突；蓝色是导航类 HMI 的通用「指引色」，也与 CarLife 体系一致。

### 2.4 语义色（Semantic）

| Token | HEX | 用途 |
|-------|-----|------|
| `--success` | `#34D399` | 连接正常、蓝牙已连、信号满格 |
| `--warning` | `#F5B942` | 弱信号、GPS 漂移、连接不稳 |
| `--danger` | `#FF5A5A` | 断开连接、播报错误、无信号 |
| `--info` | `#5AA9FF` | 中性提示（可与 accent 互换） |

> 语义色在状态条中**只用一个 10×10px 圆点 + 文字**表达，不要做成大色块。

### 2.5 描边与分隔

| Token | HEX | 用途 |
|-------|-----|------|
| `--border-subtle` | `#232A36` | 卡片内分隔线、页签栏底线（几乎不可见，只作结构暗示） |
| `--border-strong` | `#333D4D` | 需要明确边界时（音频页按钮组外框），**慎用** |

## 3. Typography（排版 · 远距离中文车机字阶）

### 3.1 距离与尺寸推导

驾驶者眼睛距车机屏约 **60–80cm**（手机 UI 的 2–3 倍距离）。因此：
- **基准正文 = 32px**（约为手机 16px 的 2 倍）
- **最小可读字号 = 24px**（绝对下限，且只允许用于 `--fg-secondary` 级以上颜色）
- **禁止出现 < 24px 的任何文字**

### 3.2 字体栈

中文车机场景优先系统级中文字体，避免 Web 字体加载抖动。

```css
--font-sans: "HarmonyOS Sans SC", "HarmonyOS Sans", "Noto Sans SC",
             "Source Han Sans SC", "PingFang SC", "Microsoft YaHei",
             system-ui, -apple-system, "Segoe UI", sans-serif;

/* 数字专用：转向距离、里程、时间、播放时间 —— 用等距数字保证不跳动 */
--font-tnum: "HarmonyOS Sans SC", "DIN Alternate", "Roboto Mono",
             ui-monospace, "SF Mono", Consolas, monospace;
```

> 数字一律加 `font-variant-numeric: tabular-nums;`，防止倒计时/距离变化时数字宽度抖动。

### 3.3 字阶（Scale）

| 级别 | Token | Size | Weight | Line-height | Letter-spacing | 用途 |
|------|-------|------|--------|-------------|----------------|------|
| **Mega** | `--type-mega` | **120px** | 700 | 1.0 | -2px | **转向距离数字**「300」（导航页绝对焦点） |
| **Display** | `--type-display` | **72px** | 700 | 1.05 | -1px | 需要极强冲击的备用大数字（掉头距离、剩余里程大数） |
| **H1** | `--type-h1` | **48px** | 700 | 1.2 | 0 | 道路名/下一步动作「科技路」、大头歌名 |
| **H2** | `--type-h2` | **40px** | 600 | 1.25 | 0 | 导航动作短句、时间「14:32」 |
| **H3** | `--type-h3` | **32px** | 600 | 1.3 | 0 | 卡片小标题、歌手名、状态条主值 |
| **Body** | `--type-body` | **32px** | 400 | 1.4 | 0 | 正文基准（如「前方路口右转进入科技路」整句） |
| **Body-Sm** | `--type-body-sm` | **28px** | 400 | 1.4 | 0 | 次级正文（剩余里程、EAT） |
| **Label** | `--type-label` | **26px** | 500 | 1.3 | 0.5px | 状态条标签、页签名、单位后缀「m/km」 |
| **Caption** | `--type-caption` | **24px** | 500 | 1.3 | 0.5px | 最小可用字号（仅限非关键辅助信息） |

**字重使用纪律**：只允许 `400 / 500 / 600 / 700`。导航页 120px 数字与 48px 道路名用 **700**；状态条用 **500/600**。**禁止 300 以下细字**（车机反光下直接消失）。

| 元素 | 字号 | 字重 | 颜色 |

| 距离单位「m」 | 48px | 600 | `--fg-secondary` |
| 道路名「科技路」 | 48px | 700 | `--fg-primary` |
| 动作整句「前方路口右转进入科技路」 | 32px | 400 | `--fg-secondary` |
| 状态条·时间「14:32」 | 40px | 600 | `--fg-primary` |
| 状态条·剩余里程「12.4 km」 | 28px | 400 | `--fg-secondary` |
| 状态条·EAT「预计 14:47 到达」 | 28px | 400 | `--fg-secondary` |
| 状态条·标签「剩余 / 到达」 | 26px | 500 | `--fg-tertiary` |
| 页签名「导航 / 音频」 | 26px | 500 | 激活=`--accent`，非激活=`--fg-tertiary` |

### 3.5 音频页字阶映射

## 4. Spacing & Radius（间距与圆角）

### 4.1 间距刻度（4 / 8 基准）

车机场景间距整体放大 1.5–2 倍，避免元素挤在一起。

| Token | Value | 用途 |
|-------|-------|------|
| `--space-1` | 4px | 图标与文字基线微调 |
| `--space-2` | 8px | 紧凑内联（数字与单位之间） |
| `--space-3` | 12px | 小间隙 |
| `--space-4` | 16px | 卡片内元素间距 |
| `--space-5` | 24px | 卡片内边距（基础） |
| `--space-6` | 32px | 卡片内边距（大卡片）、元素组间距 |
| `--space-8` | 48px | 卡片之间间距、页面边距 |
| `--space-10` | 64px | 主区域之间的分隔（导航页焦点卡与地图之间） |
| `--space-12` | 96px | 页面外边距（超宽屏两侧呼吸） |

### 4.2 页面栅格（1920 × 720）

- **画布**：1920 × 720，安全边距 `--space-8`（48px）内收。
- **导航页分栏**：左「转向指引卡片」宽 **640px**，右「地图区」自适应填满剩余（约 1920 − 640 − 96 = **1184px**）。
- **顶部页签栏**：高 **72px**，横跨全宽。
- **底部状态条**：高 **88px**，横跨全宽。
- 导航页内容区有效高度：720 − 72 − 88 − 边距 ≈ **500px**。

### 4.3 圆角规范

| Token | Value | 用途 |
|-------|-------|------|
| `--radius-sm` | 8px | 标签、小色块、状态圆点容器 |
| `--radius-md` | 16px | 按钮、进度条、页签激活底、图标容器 |
| `--radius-lg` | 24px | **卡片容器**（转向指引卡片、曲目卡片） |
| `--radius-xl` | 32px | 大面板/浮层（音频控制面板） |
| `--radius-pill` | 999px | 音量条、进度条轨道、圆形播放按钮 |

> 车机按惯例用**较大的圆角（16–24px）**，视觉更柔和、边缘更不容易误读为「UI 断裂」。

## 5. Component Styles（组件规范）

### 5.1 转向指引卡片（Turn Card）— 导航页唯一焦点

```
容器
- 尺寸：640 × 460px（位于左栏，垂直居中偏上）
- 背景：--bg-surface (#141821)
- 圆角：--radius-lg (24px)
- 边框：1px solid --border-subtle (#232A36)  // 极淡，仅作结构暗示
- 内边距：--space-6 (32px)
- 阴影：0 12px 40px rgba(0,0,0,0.55)  // 车机深底需要更深阴影撑起层级

内部结构（自上而下）
1. 转向箭头图标容器
   - 尺寸：160 × 160px 圆形
   - 背景：--accent-dim (#1A3A5C)
   - 发光：0 0 40px --accent-glow  // 全屏唯一允许发光处
   - 图标：白色箭头，--accent (#2E9BFF) 可作描边色
2. 距离行（水平基线对齐）
   - 数字：--type-mega (120px / 700 / --fg-primary)
   - 单位：--type-h1 (48px / 600 / --fg-secondary)，数字右侧 baseline 对齐
   - 间距：--space-2 (8px)
3. 道路名
   - --type-h1 (48px / 700 / --fg-primary)
4. 动作整句
   - --type-body (32px / 400 / --fg-secondary)
   - 与道路名间距：--space-4 (16px)
```

**层级规则**：卡片内亮度递减 —— 箭头(强调) → 距离数字(纯白) → 道路名(纯白) → 整句(次级灰)。

### 5.2 大按钮 / 播放控制（Transport Button）

三个播放按钮：上一首 / 播放暂停 / 下一首。**远距离可点**，触控逻辑虽不走回传，但视觉要「像能按」。

```
尺寸
- 主按钮（播放/暂停）：144 × 144px
- 次按钮（上一首/下一首）：112 × 112px
- 间距：--space-8 (48px)

主按钮（播放/暂停）
- 背景：--accent (#2E9BFF)
- 图标：--fg-on-accent (#06131F)，尺寸 64px
- 圆角：--radius-pill (999px 圆形)
- Hover：--accent-hover (#4FB0FF)
- Active：--accent-active (#1C7FE0)
- 阴影：0 8px 24px rgba(46,155,255,0.30)

次按钮（上一首/下一首）
- 背景：--bg-elevated (#1E2430)
- 图标：--fg-primary (#FFFFFF)，尺寸 52px
- 圆角：--radius-pill
- Hover/Active：--bg-elevated-hover (#28303F)
- 边框：1px solid --border-subtle
```

> **最小触控目标 = 96×96px**（远超手机 44px 标准，因为车内颠簸 + 远距离）。

### 5.3 卡片容器（Card）

```
- 次路：stroke 5px，--border-subtle (#232A36)
- 规划路径：stroke 12px，--accent (#2E9BFF)，圆头圆角
- 背景色块（绿地/水域等）：--bg-elevated (#1E2430) 极低对比

自车位置
- 三角箭头：边长 48px，填充 --accent (#2E9BFF)，白色描边 3px
- 外围光环：半径 64px，--accent-dim 半透明
```

## 6. Depth & Elevation（深度与层级）

| Level | Token | Shadow | 用途 |
|-------|-------|--------|------|
| Flat | `--elev-0` | none | 地图底、状态条、页签栏 |
| Raised | `--elev-1` | `0 8px 32px rgba(0,0,0,0.45)` | 卡片容器 |
| Floating | `--elev-2` | `0 12px 40px rgba(0,0,0,0.55)` | 转向指引卡片（焦点） |
| Accent | `--elev-accent` | `0 8px 24px rgba(46,155,255,0.30)` | 主播放按钮 |

### Z-index Scale

| Token | Value | 用途 |
|-------|-------|------|
| `--z-base` | 0 | 内容层 |
| `--z-map` | 10 | 地图层 |
| `--z-card` | 20 | 卡片/浮层 |
| `--z-bar` | 100 | 页签栏、状态条（常驻顶层） |
| `--z-overlay` | 300 | 全屏遮罩（如倒车/来电，本期不做） |

> **深色阴影策略**：车机深底上阴影几乎不可见，**层级主要靠「背景亮度差 + 边框」表达**，阴影只作辅助。这是与浅色 Web 设计最大的差异点。

## 7. Cautions（设计注意事项 · 车机 HMI 专属）

### 绝对禁止（Never Do）

1. **禁止 < 24px 的任何文字**。远距离 + 车内反光下完全不可读。
2. **禁止低对比度灰字**。`--fg-disabled (#4A5364)` **不得承载任何信息**，只可用于装饰性占位。区分主次靠 `--fg-primary` vs `--fg-secondary`（≥11:1），不靠「更灰」。
3. **禁止 >2 个高饱和色同时出现**。强调色只有 `--accent` 一个；语义色一次只亮一个。
4. **禁止花哨动画**：无位移、无缩放、无轮播、无 loading 旋转过场。最多允许 ≤150ms 透明度过渡。
5. **禁止密集小字排版**：单行文字不超过 **22 个中文字符**；宁可截断换行，不要压小字号。
6. **禁止浅色主题 / 半透明玻璃拟态**：本界面**只有深色**，且不要用 blur 半透明（车机芯片性能与夜间可读性都不适）。
7. **禁止纯黑 #000000 作底**：OLED 纯黑在车内白炽灯反光下会显脏、且与边框无差分。用 `--bg-base (#0A0C10)`。
8. **禁止用彩色边框/色块分区**。分区靠间距 + 亮度差。
9. **禁止把重要信息放在屏幕最下缘 20px 内**——车机常有物理边框遮挡/反光。
10. **禁止触控目标 < 96×96px**。

### 推荐（Prefer）

- 层级用「**字号 + 亮度**」双维度拉开，而非颜色。
- 焦点区（转向指引）占据视觉重量 **> 40%** 的屏面。
- 数字用 `tabular-nums`，保证跳动时不抖动。
- 大量留白：卡片之间 48px 起，页面边距 48px 起。
- 强调色面积 ≤ 8% 屏面，且集中在「你现在该看的那个东西」上。

### 首屏必须出现（导航页）

1. **转向动作 + 距离数字**（120px 级别）—— 这是驾驶第一需求，必须在 1 秒内可读。
2. **道路名 / 下一步动作** —— 告诉驾驶者「往哪走」。
3. **地图占位 + 自车三角箭头** —— 建立空间感。
4. **状态条四项**：时间、剩余里程、预计到达、连接状态。
5. **两个页签**：导航（激活）/ 音频。

### 首屏必须出现（音频页）

1. **曲目名 + 歌手名**（48/32px）。
2. **三个大播放按钮**（主按钮 144px）。
3. **播放进度条 + 时间**。
4. **音量条**。

### 夜间驾驶专项

- 全屏平均亮度压低：大面积使用 `--bg-base/#0A0C10`，高亮区仅集中在焦点。
- 不使用纯白大面积填充（除图标/文字），避免眩光。
- 状态指示用「小圆点 + 文字」，不用整条彩色横幅。

## 8. Responsive Behavior（响应式行为）

本界面为**固定 1920×720 车机画布**，不做移动端适配。但需处理以下非 16:9 情况：

| 场景 | 处理 |
|------|------|
| 宽度 > 1920px（超宽车机） | 地图区横向拉伸，转向卡片宽度锁定 640px 不变，居中区域两侧加留白 |
| 宽度 < 1920px（集装箱式窄屏） | 优先压缩地图区宽度，**禁止**缩小字号；转向卡片最小宽度 560px |
| 高度 ≠ 720px | 页签栏(72) 与状态条(88) 固定高，仅弹性缩放中间内容区；内容超高时**优先减内容，不减字号** |
| DPI / 缩放变化 | 所有尺寸以 px 写成设计值；落地时按车机实际分辨率等比缩放整屏（整数倍优先，避免半像素模糊） |

**硬约束**：字号**永不随窗口缩小**。信息挤不下 → 删信息，不是缩小字。

## 9. Agent Prompt Guide（Agent 生成指南）

### Key Instructions

- **这是车机屏，不是手机 App**：默认字号是 32px 起，不是 16px。任何 24px 以下的文字都是 bug。
- **只有深色**：不要生成浅色版本，不要用 `prefers-color-scheme`。
- **导航页焦点唯一**：转向指引卡片是唯一高亮区，其余元素亮度自动降一档。
- **强调色克制**：全屏 `--accent (#2E9BFF)` 面积 ≤8%，只在「当前动作/关键数据/激活态」。
- **不用边框和色块分区**：用间距 + 亮度分层。
- **数字加 `tabular-nums`**，字体用 `--font-tnum` 栈。
- **静态稿**：不写动画/交互 JS，只出视觉。按钮 hover/active 用 CSS `:hover/:active` 预留。
- **中文优先**：默认文案用中文，字号按中文字面宽度留足空间（中文比拉丁宽 ~1.6 倍）。
