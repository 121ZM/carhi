## 3.5 「独立投屏窗口能否像画中画一样」——SDK 核实结论（本轮补查）

- **PiP 内容只能是 XComponent**：`PiPConfiguration.componentController: XComponentController`
  必填；`PiPTemplateType` 只有 `VIDEO_PLAY/VIDEO_CALL/VIDEO_MEETING/VIDEO_LIVE`。
  `customUIController?: NodeController` 官方注释是「PiP 页面上的**自定义 UI（控件）**」，
  **不是内容容器** —— 不能拿它塞 MapView。
- **PiP 免权限**（整个 d.ts 无 `@permission`），`isPiPEnabled()` 可查设备支持。
  但 `PiPWindowInfo` 只有 `{windowId, size}`，**没有屏幕坐标** ⇒ 喂不了 `SetCaptureArea`。
- **floatView 与 PiP 互斥**：`start()` 的 `1300034` 明确写 "App has already started
  floating ball or pip window"。
- **floatView 启动前提**：`1300033` —— 主窗口必须在前台（`start()` 时），启动后可切走。
  尺寸有 `getFloatViewLimits()`（min/max/比例），可据此锁 16:9。
- 结论：要「小窗里是高德地图且能浮在别的 App 上」**只有 floatView 一条路**（等 FLOAT_VIEW）。

### 3.6 补查：「游戏/视频的小窗走的哪条路」（大哥追问）

- **视频类（含微信视频通话）→ 系统 PiP**：内容天然是 Surface，正好满足
  `componentController: XComponentController`；`PiPTemplateType` 四个模板全是视频语义。
- **游戏类 → 系统侧窗口管理，不是 App API**：`@ohos.window` 里**没有 `setWindowMode`**
  之类的"把自己切成 FLOATING"的接口。可查到的只有：
  - `getWindowStatus()` 只读，`WindowStatusType.FLOATING = 4` 是**读取值**；
  - `resize()/moveWindowTo()` **只在已处于 FLOATING 时**才生效；
  - `setSupportedWindowModes()` 只是**声明允许哪些模式**（PC 自由窗口用），不切换。
  ⇒ 手机的"游戏小窗"由智慧多窗/应用助手把**整个应用窗口**切成 FLOATING，用户手势触发。
- **我们两条都不顺**：MapView 是 ArkUI 组件树、没有可交付的 Surface（PiP 装不进）；
  非系统应用不能自己切 FLOATING。⇒ 只剩 `floatView`（它本来就是给非视频内容准备的）。


## 4. ★★ 大哥定方向：「走系统窗口管理」——已实现（2026-10-18 早）

即：**应用自己不开窗**，由用户用系统「智慧多窗」把 CarHi 拖成悬浮小窗，
应用检测到 FLOATING 后自动接管。这条路径**不需要任何权限**。

### 4.1 前提（之前缺的就是这个）

`module.json5` 的 ability 里**原先没有 `supportWindowMode`**，系统默认只允许 fullscreen
⇒ 用户**根本拖不出小窗**。已加：

```json5
"supportWindowMode": ["fullscreen", "split", "floating"],
"preferMultiWindowOrientation": "landscape",
```

已核对**打包产物** `intermediates/res/default/module.json` 里确实带上了这两项
（只看源码不算验证 —— 配置字段写错名会被静默忽略）。

### 4.2 代码改动

- `Index.ets`：新增 `@State floatMode`；`startRegionWatch()` 改为 **aboutToAppear 无条件注册**
  （系统手势随时发生，晚注册就完全没反应）；启动时用 `getWindowStatus()` 补查一次
  （应用可能**以悬浮窗身份被拉起**，那种情况不触发 statusChange）；
  新增 `enterFloatMode()` / `exitFloatMode()`
- `build()`：新增 `floatMode` 分支 —— 整屏换成 `MapPage({ chrome: false })`；
  同时把 `showAmapNavi` / `showRealMap` 的条件加上 `!this.floatMode`
  （高德地图实例只能有一个，两套同时渲染会打架）
- `MapPage.ets`：新增 `chrome: boolean = true` 属性。**投屏用的地图必须关掉顶部操作栏**，
  否则「返回设置 / 投屏到车机」按钮会一起被采集进车机画面
- 设置页新增小窗状态卡片（绿色=已在小窗 / 灰色=使用说明）
